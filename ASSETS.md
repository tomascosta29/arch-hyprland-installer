# Asset provenance

The repository currently contains three bundled wallpaper files:

| Theme | File | Recorded source/license |
|---|---|---|
| Nordfox (`fcosta`) | `dotfiles/themes/fcosta/wallpaper.png` | Unknown |
| Catppuccin Macchiato | `dotfiles/themes/catppuccin-macchiato/wallpaper.png` | Unknown |
| Tokyo Night | `dotfiles/themes/tokyo-night/wallpaper.png` | Unknown |

The Nordfox and Catppuccin files are byte-identical. The Tokyo Night file
contains JPEG data despite its `.png` suffix.

These files predate the repository audit and contain no embedded attribution
that establishes redistribution rights. Before publishing a release, replace
them with owned or permissively licensed artwork and record the author, source
URL, license name, and license text here.
